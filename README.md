# 漫集社 — 在线漫画阅读网站

## 一、项目介绍

漫集社是一款基于Flask \+ MySQL开发的轻量级在线漫画阅读系统。项目实现了漫画展示、分类浏览、关键词搜索、用户注册登录、个人书架、阅读记录、漫画收藏、评论评分、手机号找回密码等完整功能。整体界面简洁美观，交互流畅，人机交互体验良好。

## 二、技术栈

- **后端**：Python Flask、MySQL、mysql\-connector

- **前端**：HTML、CSS、原生JavaScript（Ajax 异步交互）

- **数据库**：MySQL 8\.0（utf8mb4 字符集、InnoDB 引擎）

## 四、数据库设计

项目数据库名为 **manjishe**，共包含六张数据表：

- **user 用户表**：存储账号、密码、绑定手机号，支持账号密码登录、密码找回

- **comic\_info 漫画表**：存储漫画封面、标题、作者、分类、简介等信息

- **bookshelf 书架表**：记录用户追更漫画、上次阅读章节

- **favorite 收藏表**：记录用户收藏的漫画及收藏时间

- **history 阅读记录表**：自动记录用户的漫画浏览记录

- **comment 评论表**：存储用户评论内容、星级评分、评论时间

## 五、系统功能模块

### 1\. 基础浏览功能

- 首页展示全部漫画卡片

- 按分类筛选漫画

- 根据漫画名称、作者模糊搜索

### 2\. 用户账号功能

- 用户注册（账号、密码、手机号必填，格式校验、重复检测）

- 用户登录（异步弹窗提示错误，无空白跳转）

- 手机号找回重置密码功能

- 登录状态保持、退出登录

### 3\. 漫画阅读功能

- 漫画详情信息展示

- 章节列表切换、上下章翻阅

- 自动记录阅读历史

- 加入书架、取消书架

- 收藏漫画、取消收藏

### 4\. 互动功能

- 用户对漫画进行 1\~5 星评分

- 发表文字评论

- 评论按时间倒序展示

### 5\. 个人中心功能

- 我的书架：展示所有追更漫画，点击直接阅读

- 阅读记录：查看全部浏览过的漫画

- 我的收藏：展示所有收藏漫画

## 六、项目运行方式

1\. 安装项目依赖

```Plain Text
pip install flask mysql-connector-python
```

2\. 打开 MySQL，创建数据库

```Plain Text
CREATE DATABASE manjishe DEFAULT CHARSET utf8mb4;
```

3\. 导入项目所有数据表 SQL

4\. 修改 app\.py 中 MySQL 账号、密码为自己本地数据库信息

5\. 运行项目

```Plain Text
python app.py
```

6\. 浏览器访问：`http://127.0.0.1:5000`
